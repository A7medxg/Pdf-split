PDF Chapter Splitter - النسخة 2

تطبيق ويب يرفع كتاب PDF، يستخرج نصه، يكتشف الفصول، يتيح لك مراجعتها في جدول واحد، ثم يصدّر ملف TXT لكل فصل وملف ZIP يجمعها.

المتطلبات
1- Python 3.10 أو أحدث.
2- اتصال بالإنترنت أول مرة لتثبيت المكتبات.

التشغيل
1- فك ضغط المشروع وافتح الطرفية داخل المجلد.
2- (اختياري) أنشئ بيئة افتراضية:
   ويندوز:  py -m venv .venv  ثم  .venv\Scripts\activate
   ماك/لينكس:  python3 -m venv .venv  ثم  source .venv/bin/activate
3- pip install -r requirements.txt
4- streamlit run app.py

ما الذي تحسّن عن النسخة الأولى
1- اكتشاف الفصول يعتمد أولًا على فهرس PDF الداخلي (Bookmarks) إن وُجد، ثم أنماط العناوين، ثم حجم الخط. يمكنك اختيار الطريقة يدويًا أو اختيار حجم الخط ومستوى الفهرس.
2- الأنماط تدعم Chapter / Part بالأرقام والرومانية والكلمات، وتدعم الفصل / الباب بالأرقام العربية والكلمات (الأول، الثاني عشر...). وتتجاهل الجمل العادية مثل: Chapter 3 discusses...
3- العناوين المكوّنة من سطرين (Chapter 3 ثم عنوان الفصل) تُدمج تلقائيًا. صفحة Part I الفاصلة لا تصبح ملفًا مستقلًا.
4- الفصل الذي يبدأ في منتصف الصفحة يُقسم على مستوى السطر، فلا يضيع آخر الفصل السابق ولا يدخل في الفصل الجديد.
5- صفحات الفهرس المطبوع وصفحات حقوق النشر تُكتشف كصفحات كاملة وتظهر في قائمة تعدّلها بنفسك قبل التصدير. أسطر حقوق النشر الواضحة فقط (©، ISBN، All rights reserved) تُحذف على مستوى السطر، فلا تُحذف جملة عادية فيها كلمة published by.
6- الترويسات المتكررة وأرقام الصفحات تُزال تلقائيًا.
7- صفحات العمودين تُرتّب بالترتيب الصحيح (يسار ثم يمين، أو العكس للنص العربي).
8- الحواشي السفلية تُفصل عن المتن (خط أصغر أسفل الصفحة) ولك أن تنقلها لنهاية الفصل أو الصفحة، أو تتركها أو تحذفها.
9- أسطر الفقرة تُدمج في فقرة واحدة، والكلمات المقطوعة بشرطة آخر السطر تُصلح، والفقرة التي تنتهي في صفحة وتكمل في التالية تُدمج.
10- جدول واحد للمراجعة (تضمين، عنوان، صفحة البداية) بدل عشرات الصناديق، مع إمكانية إضافة صفوف وحذفها.
11- ملفات PDF المحمية بكلمة مرور تُفتح إذا أدخلت كلمة المرور الصحيحة. التطبيق لا يتجاوز أي حماية.
12- ملف مستقل لما قبل أول فصل حتى لا يضيع نص بصمت.
13- الفصول القصيرة جدًا تظهر في تنبيه لأنها غالبًا عناوين خاطئة.

حدود معروفة
1- ملفات PDF المصوّرة بلا نص (تحتاج OCR) غير مدعومة.
2- بعض الملفات العربية القديمة تُخزَّن بترتيب بصري معكوس، فيستخرجها PyMuPDF معكوسة. هذا يعتمد على الملف نفسه.
3- كشف الحواشي يعتمد على الخط الأصغر أسفل الصفحة؛ جداول أو تعليقات صغيرة أسفل الصفحة قد تُعامل كحواشي (اختر تركها في مكانها عند الحاجة).
4- دمج الكلمة المقطوعة يحذف شرطة الوصل عند كلمة مثل pre-industrial إذا انقسمت على سطرين.
5- الاكتشاف التلقائي تقريبي. راجع الجدول دائمًا.

هيكل المشروع
- app.py : واجهة Streamlit
- core.py : منطق الاستخراج والاكتشاف والتنظيف (بدون اعتماد على Streamlit)
- tests/test_core.py : اختبارات للمنطق
- run_tests.py : تشغيل الاختبارات بدون pytest (python run_tests.py)
- requirements.txt
